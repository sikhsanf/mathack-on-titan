# Mathack on Titan

Game matematika side-scrolling ala voxel untuk anak (Pra-K s/d K, sampai 6 tahun). Jawab soal (kurikulum Singapore, dari app LearnersFam) untuk mengalahkan Titan lucu. Satu file `index.html`, portrait, ID/EN, PWA.

**Install:** buka https://sikhsanf.github.io/mathack-on-titan/ di Chrome HP → menu ⋮ → *Install app* / *Add to Home screen*.

`src/` = sumber game, `tools/` = skrip build. Prototipe v0.2: dunia Padang Bunga, 3 stage, solo.
